# FundTrack

**کیف پول هوشمند ترید، حسابداری شخصی و موتور اهداف**

داشبورد یکپارچه برای ژورنال ترید MT5، مدیریت مالی شخصی، پیگیری بدهیها و پیشبرد اهداف — با پشتیبانی فارسی و راستبهچپ.

</div>

---

## ✨ چکیده

FundTrack یک اپ وب **مستقل** است که تمام ابزارهای یک معاملهگر و مدیر مالی شخصی را در یکجا جمع میکند:

- 📓 **ژورنال ترید** — ثبت و آنالیز تریدهای MT5، محاسبه R-multiple، سشنها، ساعتهای معاملاتی و هیت‌مپ.
- 💰 **حسابداری شخصی** — حسابهای بانکی/نقد/کیف‌پول، تراکنشها، وامها و بدهیها، خطوط اعتباری.
- 🎯 **موتور اهداف** — تعریف هدف، تخصیص سود هفتگی، مأموریتها و اشانها با عناصر گیمیفیکیشن.
- 🧠 **دستیار هوشمند** — ثبت سریع تراکنش/ترید به زبان طبیعی و اجرای کارها.
- 📅 **تقویم شمسی** — تعطیلات، رویدادهای اقتصادی و یادآوریها.

---

## 🗂 معماری

```
مرورگر (React + Vite + Tailwind v4)
        │
        │  HTTP (local network)
        ▼
سرور یکپارچه Express (server.ts)
        ├─ سرو کردن فرانت (توسعه با Vite)
        ├─ API نرخ ارز / تقویم شمسی (با کش و fallback)
        ├─ API فایل رویداد MT5
        ├─ خروجی تک‌فایل HTML
        └─ API دیتابیس SQLite (همگام‌سازی بین دستگاه‌ها)
```

### ذخیره‌سازی داده

- داده‌ها در یک فایل **SQLite** (`data/fundtrack.db`) روی همان سرور ذخیره می‌شوند.
- گوشی و کامپیوتر هر دو به یک سرور در شبکه محلی وصل می‌شوند و **داده مشترک** می‌بینند.
- یک کپی محلی در `localStorage` مرورگر نیز نگه داشته می‌شود تا آفلاین کار کند.

## 🚀 اجرا روی سیستم خودتان

#### پیش‌نیاز
- **Node.js 18+** (ترجیحاً آخرین LTS)

#### با یک کلیک (ویندوز)
برای اجرای خودکار همه‌چیز، روی فایل **`Start-FundTrack.bat`** دابل‌کلیک کنید.
اسکریپت به‌طور خودکار وابستگی‌ها را بررسی/نصب و سرور را بالا می‌آورد و مرورگر را باز می‌کند.

#### دستی
```bash
npm install --legacy-peer-deps
npm run dev
```
سپس مرورگر را باز کنید: **http://localhost:3000**

---

## 📱 دسترسی از گوشی (شبکه محلی)

1. گوشی و کامپیوتر باید به **یک وای‌فای/مودم** وصل باشند.
2. آدرس `http://IP-کامپیوتر:3000` را در مرورگر گوشی باز کنید.
   - برای پیدا کردن IP: `ipconfig` در PowerShell → مقدار `IPv4 Address` زیر Wi-Fi.
3. چون هر دو دستگاه به یک دیتابیس SQLite وصل‌اند، داده‌ها **مشترک** هستند.

> نکته: برای مشاهده‌ی آخرین تغییرات از دستگاه دیگر، کافی است صفحه را رفرش کنید.

---

## 🔒 یادداشت امنیتی

- سرور روی شبکه محلی (LAN) باز است؛ اتصال آن به اینترنت عمومی توصیه نمی‌شود.
- داده‌های مالی به‌صورت متن ساده در فایل SQLite ذخیره می‌شوند؛ در صورت نیاز، رمزنگاری در سطح دیسک (مثلاً BitLocker) را فعال کنید.
- برای محیط‌های مشترک/عمومی، افزودن لایه احراز هویت پیشنهاد می‌شود.

## 📄 ساخت تک‌فایل HTML

برای خروجی یک فایل HTML کاملاً مستقل (بدون نیاز به سرور):
```bash
npm run build:singlefile
```
فایل حاصل در `dist-single/index.html` قرار می‌گیرد.
