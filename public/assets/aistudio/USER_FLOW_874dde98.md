# FundTrack — نقشه جریان‌های کاربر (User Flow)

این سند جریان‌های اصلی کاربر در FundTrack را با نقاط ورود، تصمیم‌ها و حالت‌های خطا توصیف می‌کند. نسخه به‌روزرسانی‌شده با آخرین ویژگی‌های پنل (به‌روزرسانی خودکار نرخ دلار، اخبار اقتصادی، مأموریت‌های سفارشی، تنظیمات ظاهری پیشرفته و …).

## پیمایش کلی

```
سایدبار
├── داشبورد        → KPI ها، گیمیفیکیشن، اعلان‌ها، آخرین معاملات، اهداف نزدیک
├── ژورنال        → جدول معاملات + فیلتر + مرتب‌سازی + صادرات CSV
├── آنالیز        → هیت‌مپ/بریک‌داون، نسبت خرید/فروش، بهترین روز
├── حساب‌ها       → مدیریت حساب‌های MT5 + همگام‌سازی دستی
├── هدف‌گذاری     → ساخت/برنامه‌ریزی/فعال‌سازی هدف
├── حسابداری      → تب‌ها: خلاصه | حساب‌ها | تراکنش‌ها | هزینه‌ها
│     └─ تنظیمات حسابداری ← نرخ دلار به تومان (خودکار)
├── مأموریت‌ها    → تب‌ها: امروز | اهداف | نشان‌ها | سفارشی
├── اخبار         → رویدادهای اقتصادی + تعطیلات
├── تنظیمات       → تم/زبان/ارز/پس‌زمینه/رمز PIN
└── وضعیت         → اتصال، سلامت سیستم، شمارنده‌ها
```

---

## جریان ۱ — راه‌اندازی و شناسایی حساب

```
اجرای برنامه
   │
   ▼
صفحه داشبورد (خالی)
   │
   ▼
اجرای اک‌سپرت MT5 → نوشتن events.jsonl
   │
   ▼
همگام‌سازی خودکار (حلقه پس‌زمینه، هر ~۵ ثانیه) / دکمه «به‌روزرسانی»
   │
   ▼
شناسایی خودکار حساب‌ها + ساخت معاملات
   │
   ▼
وضعیت: «فعال — فایل رویداد موجود است»
```
- **خطا:** فایل رویداد یافت نشود → وضعیت «غیرفعال»؛ هیچ معامله‌ای نمایش داده نمی‌شود. صفحه «وضعیت» مسیر دیتابیس و آخرین خطا را نشان می‌دهد.

---

## جریان ۲ — روال روزانه تریدر

```
داشبورد
   │
   ├─ بررسی KPI (سود خالص، تعداد ترید، نرخ برد/پروفیت‌فکتور، میانگین R، بهترین/بدترین، Max DD، مدت متوسط)
   ├─ بررسی گیمیفیکیشن (ستاره امروز، مأموریت‌های فعال) + «مشاهده همه»
   ├─ مشاهده اعلان‌ها (سررسیدها) و اقدام
   ├─ مرور «آخرین معاملات»
   ├─ ویجت «اهداف نزدیک» → پرش به صفحه هدف‌گذاری
   └─ در صورت نیاز: ژورنال/آنالیز برای تحلیل عمیق
```

---

## جریان ۳ — ثبت یک تراکنش مالی

```
حسابداری ← تب «تراکنش‌ها»
   │
   ├─ انتخاب فیلتر نوع (همه/واریز/برداشت/هزینه)
   ├─ دکمه «ثبت تراکنش»
   │     ├─ نوع و مبلغ (الزامی)
   │     ├─ ارز، حساب، تاریخ، یادداشت (اختیاری)
   │     └─ ذخیره → Toast موفقیت → لیست به‌روز
   └─ ویرایش/حذف (با تأیید)
```
- **اعتبارسنجی:** نوع معتبر، مبلغ > ۰.

---

## جریان ۴ — هزینه ثابت تکرارشونده

```
حسابداری ← تب «هزینه‌ها»
   │
   ├─ «افزودن هزینه ثابت»
   │     ├─ عنوان، مبلغ، ارز
   │     ├─ فعال‌سازی «تکرار ماهانه» + «روز ماه»
   │     └─ ذخیره
   │
   ▼
هر ماه در روز مقرر: sync خودکار تراکنش «هزینه ثابت» تولید می‌کند
   │
   ▼
اعلان «۳ روز مانده» در داشبورد
```

---

## جریان ۵ — حساب بانکی، بودجه و پرداخت قسط وام

```
۱. ساختن حساب بانکی
   حسابداری ← تب «حساب‌ها» ← «افزودن حساب»
   (نام، نوع: بانک/نقد/کیف پول، ارز USD/IRT، موجودی، یادداشت)
   └─ ویرایش/حذف/مشاهده تاریخچه تراکنش‌های حساب

۲. بودجه‌بندی
   حسابداری ← تب «هزینه‌ها» ← «افزودن سقف بودجه»
   (دسته + درصد از موجودی حساب مبدأ)
   └─ خطا: دسته تکراری ← «این دسته از قبل بودجه دارد»

۳. ثبت وام با اقساط
   حسابداری ← تب «هزینه‌ها» ← «ثبت وام/قرض/طلب»
   (نوع، عنوان، مبلغ، دوره، سررسید، تعداد اقساط، مبلغ هر قسط)

۴. پرداخت قسط
   روی وام ← دکمه «پرداخت قسط»
     ├─ انتخاب حساب بانکی
     ├─ «کسر X از حساب «Y»؟»
     ├─ اعتبارسنجی: موجودی کافی؟
     │     ├─ خیر ← خطا «موجودی کافی نیست» (بدون تغییر)
     │     └─ بله ← کسر موجودی + ثبت تراکنش out
     └─ به‌روزرسانی: اقساط پرداخت‌شده +۱، نوار تسویه،
        اگر اقساط تمام → «بسته» (سبز)
```
- **تبدیل ارز:** اگر ارز حساب بانکی با وام متفاوت باشد، با نرخ تومان حساب فعال تبدیل می‌شود؛ در نبود نرخ، خطای واضح. نرخ به‌روزرسانی خودکار در تنظیمات حسابداری (جریان ۱۱).

---

## جریان ۶ — هدف‌گذاری و برنامه‌ریزی

```
هدف‌گذاری ← «هدف جدید»
   │
   ├─ مرحله ۱ «اطلاعات»:
   │     نام، نوع (کالا/پولی)، ارز (USD/IRT)، مبلغ هدف، تاریخ هدف،
   │     منبع بودجه (weekly budget)، اولویت (۱–۵)، درصد تخصیص
   ├─ مرحله ۲ «پیش‌نمایش برنامه»: بررسی زنده
   │     مانده لازم، مبلغ ماهانه پیشنهادی، تعداد ماه‌های لازم،
   │     تاریخ تکمیل پیش‌بینی‌شده، برچسب «قابل‌اجرا» یا یادداشت‌های هشدار
   └─ «ذخیره و تأیید» → وضعیت: پیش‌نویس (draft)
   │
   ▼
فعال‌سازی هدف → وضعیت «در حال اجرا»
   │
   ▼
ویجت «اهداف نزدیک» در داشبورد + تبدیل به مأموریت روزانه (جریان ۷)
   │
   ▼
آرشیو کردن (پایان) → وضعیت «آرشیو شده»
```
- **تبدیل ارز در مأموریت:** سود امروز (دلاری) قبل از مقایسه با هدف تومانی، با نرخ `usd_toman` حساب به تومان تبدیل می‌شود تا `current` و `target` واحد یکسان داشته باشند.

---

## جریان ۷ — گیمیفیکیشن، مأموریت‌ها و نشان‌ها

```
مأموریت‌ها
   ├─ هدر Hero: سطح، نوار هفتگی/ماهانه، ستاره امروز/هفته/ماه، مجموع ستاره‌ها، XP روزانه
   ├─ تب «امروز»:
   │     کارت مأموریت‌های روزانه (ترید، برد، سود، میانگین R، لندن،
   │     معامله مثبت، نرخ برد، بهترین، رعایت حد ضرر، نسبت R) + اهداف فعال
   │     └─ در تکمیل: تیک سبز + انیمیشن + جشن + صدا (در نشان جدید)
   │     └─ ویرایش هدف/ستاره هر مأموریت (override)
   ├─ تب «اهداف»: مأموریت‌های روزانه ناشی از اهداف فعال
   ├─ تب «نشان‌ها»: ۴ نشان (سطح‌های ۱–۴) با آستانه ستاره و تاریخ کسب
   └─ تب «سفارشی»: مدیریت مأموریت‌های سفارشی
         ├─ «مأموریت جدید»:
         │     منبع (دستی/از هدف/از هزینه)، متریک (درآمد/سقف)،
         │     هدف عددی، ستاره، XP، نام
         └─ ذخیره → ارزیابی روزانه با داده‌های امروز
```
- **ورود سریع:** کارت داشبورد «مشاهده همه» → پرش به صفحه مأموریت‌ها.
- **خطا:** مأموریت با هدف صفر یا نامعتبر ← خطای اعتبارسنجی.

---

## جریان ۸ — اخبار اقتصادی و تعطیلات

```
اخبار
   ├─ «واردات» (upload) فایل رویدادها → Toast «X رویداد وارد شد»
   ├─ تب «رویدادها»:
   │     هر رویداد: تأثیر (کم/متوسط/زیاد/عادی)، شمردن معکوس،
   │     پیش‌بینی/واقعی/قبلی، دکمه زنگ هشدار
   │     └─ آلارم: «زنگ به صدا درآمد» + اعلان در داشبورد
   └─ تب «تعطیلات»: لیست تعطیلات بازار
```
- فچ خودکار از تقویم اقتصادی توسط زمان‌بند پس‌زمینه انجام می‌شود.

---

## جریان ۹ — اعلان‌ها (سررسیدها)

```
داشبورد ← کارت «اعلان‌ها»
   ├─ هر اعلان: عنوان + «X روز باقی مانده»
   ├─ دکمه «علامت‌گذاری به‌عنوان خوانده‌شده»
   └─ سررسیدهای < ۱ روز با رنگ قرمز
```
- منابع اعلان: سررسید هزینه‌های ثابت، اقساط وام، و هشدارهای اخبار اقتصادی.

---

## جریان ۱۰ — تنظیمات، ظاهر و امنیت

```
تنظیمات
   ├─ کارت «ظاهر»:
   │     تم (اوبسیدین/شفق/نیمه‌شب/مات روشن/سایبرپانک)
   │     پالت رنگ، زبان (فارسی/انگلیسی)
   │     شدت شیشه / مات، بلور و کنتراست کارت
   │     پس‌زمینه (تصویر از پیش‌تعریف/URL/آپلود + بلور و روشنایی)
   ├─ کارت «ارز»:
   │     ارز پایه (USD/IRT)، نمایش تومان، بازه پیش‌فرض
   ├─ کارت «امنیت»:
   │     تنظیم رمز PIN پنل → اجرای بعدی قفل است → ورود با PIN
   │     (PIN نامعتبر/کوتاه/عدم تطابق ← خطا)
   └─ «ذخیره همه» (در صورت تغییر) → Toast موفقیت
```

---

## جریان ۱۱ — نرخ دلار به تومان (خودکار)

```
حسابداری ← «تنظیمات حسابداری»
   ├─ بلوک «نرخ دلار به تومان (اتوماتیک)»:
   │     سوییچ «به‌روزرسانی خودکار (روزی ۳ بار)»
   │     نمایش «نرخ فعلی» (مثلاً ۲۶۶٬۹۰۰ تومان)
   │     نمایش «آخرین به‌روزرسانی» (تاریخ شمسی + ساعت)
   │     دکمه «به‌روزرسانی نرخ» (رفرش دستی)
   └─ پس‌زمینه:
         ├─ هر ۸ ساعت (روزی ۳ بار) از API «ایران مارکت» نماد USD_IRR_FREE خوانده می‌شود
         ├─ فقط وقتی سوییچ خودکار روشن باشد
         ├─ نرخ روی همه حساب‌های فعال (usd_toman) اعمال می‌شود
         └─ دکمه دستی حتی بدون سوییچ، رفرش فوری می‌گیرد
```
- **خطا:** دریافت نرخ ناموفق ← Toast «دریافت نرخ ناموفق بود»؛ نرخ قبلی حفظ می‌شود.

---

## جریان ۱۲ — وضعیت سیستم

```
وضعیت
   ├─ وضعیت اتصال: «فعال» (فایل رویداد موجود) / «غیرفعال»
   ├─ مسیر دیتابیس
   ├─ آخرین خطا (در صورت وجود)
   └─ شمارنده‌ها (تعداد …) + دکمه رفرش
```

---

## پس‌زمینه و همگام‌سازی خودکار

| رویداد | فرکانس | توضیح |
|---|---|---|
| همگام‌سازی فایل رویداد (events.jsonl) | هر ~۵ ثانیه | ساخت معاملات، تولید هزینه‌های ثابت، ارزیابی مأموریت‌ها |
| به‌روزرسانی نرخ دلار→تومان | هر ۸ ساعت (روزی ۳ بار) | فقط اگر سوییچ خودکار روشن باشد |
| فچ اخبار اقتصادی + اعلان | زمان‌بند پس‌زمینه | هشدار نزدیک‌شدن رویدادها |

---

## حالت‌های خطای کلیدی

| سناریو | رفتار |
|---|---|
| موجودی بانکی ناکافی برای قسط | خطا، بدون تغییر |
| ارز غیرقابل تبدیل (نبود نرخ) | خطای واضح |
| دریافت نرخ دلار ناموفق | Toast خطا؛ نگه‌داشتن نرخ قبلی |
| تراکنش با مبلغ نامعتبر | خطای اعتبارسنجی |
| دسته تکراری در بودجه | خطا «این دسته از قبل بودجه دارد» |
| عدم وجود فایل رویداد | وضعیت «غیرفعال» + empty state |
| مأموریت با هدف صفر | خطای اعتبارسنجی |
| رمز PIN کوتاه/عدم تطابق/اشتباه | خطا؛ بدون تغییر |
| حذف موارد (تراکنش/حساب/هدف/مأموریت) | تأیید قبلی (confirm) |
