## ۱. مرور و اهداف

FundTrack یک داشبورد **محلی و آفلاین** برای تریدرهای MT5 است که رویدادهای اک‌سپرت را به شکل `events.jsonl` می‌نویسد. برنامه آن را می‌خواند، معاملات را می‌سازد و یک نگاه کامل از عملکرد معاملاتی **و** وضعیت مالی شخصی ارائه می‌دهد.

**اهداف بیزینس:**
1. **شفافیت معاملاتی:** ژورنال، آنالیز و داشبورد عملکردی کامل.
2. **انضباط و تعامل:** گیمیفیکیشن و مأموریت‌های روزانه برای کاهش معاملات احساسی.
3. **مدیریت مالی یکپارچه:** حسابداری شخصی، هزینه‌ها، وام‌ها و بودجه‌بندی در کنار حساب معاملاتی.
4. **حریم خصوصی و امنیت:** داده‌ها فقط روی دستگاه کاربر؛ رمز پنل اختیاری.

**مناطق غیرهدف (Non-goals):** بدون سرور ابری، بدون ثبت‌نام، بدون MT5 autotrade یا اجرای ترید؛ بدون چندکاربره.

## ۲. کاربران (Personas)

| Persona | نیاز اصلی |
|---|---|
| **تریدر اک‌سپرت** | دیدن عملکرد (سود/نرخ برد/مدت)، ژورنال، آنالیز سشن/ساعت/نماد |
| **تریدر منضبط** | مأموریت‌های روزانه، ستاره، سطح، نشان، نوار هفتگی/ماهانه |
| **کاربر مالی شخصی** | ثبت واریز/برداشت/هزینه، هزینه ثابت تکرارشونده، وام با اقساط، بودجه دسته‌ای |

## ۳. معماری و تکنولوژی

- **بک‌اند:** Python · FastAPI · SQLite (WAL)
- **فرانت:** React + TypeScript + Vite + Tailwind v4 + Recharts
- **ساختار ماژول‌های پایتون:**
  - `ingest.py` — خواندن رویدادهای MT5
  - `trades.py` — ساخت معاملات از deals
  - `analytics.py` — آنالیز/هیت‌مپ/بریک‌داون
  - `goals.py` — برنامه‌ریزی اهداف
  - `missions.py` — گیمیفیکیشن (مأموریت‌ها/ستاره/سطح/نشان)
  - `finances.py` — بودجه ترید و تخصیص به اهداف
  - `accounting.py` — تراکنش‌ها/حساب بانکی/تعهدات/بودجه/اعلان‌ها
  - `service.py` / `api.py` — سرویس و HTTP
- **اجرا:** `python -m fundtrack --no-browser` → `http://127.0.0.1:8787`
- **رابط:** RTL/LTR، تم تیره/روشن، پالت رنگ، i18n (fa/en)

## ۴. ماژول‌های عملکردی

### ۴.۱ داشبورد
- **طراحی:** KPI ها + ویجت‌های مستقل (گیمیفیکیشن، اهداف نزدیک، بودجه ترید، حسابداری، منحنی، دوره، آنالیز، معاملات اخیر).
- **KPI:** سود خالص، تعداد ترید، نرخ برد، میانگین R، بهترین/بدترین، بیشینه افت، مدت متوسط.
- **Figجت‌ها:**
  - گیمیفیکیشن: سطح، ستاره‌های امروز/کل، «X از Y»، ۳ مأموریت فعال، دکمه «مشاهده همه».
  - خلاصه حسابداری: درآمد/هزینه/خالص ماه + سررسیدهای نزدیک.
  - اعلان‌ها: لیست خوانده‌نشده + دکمه علامت‌گذاری.
  - منحنی سود تجمعی و عملکرد دوره‌ای.

### ۴.۲ ژورنال
- جدول کامل معاملات بسته‌شده با فیلتر (بازه، حساب، نماد، جهت، منبع، سشن).
- صفحه‌بندی، خروجی CSV.

### ۴.۳ آنالیز
- هیت‌مپ سود (روز هفته × ساعت)، سود بر اساس ساعت/روز/سشن/نماد، مدت نگه‌داری، بریک‌داون و «بهترین/بدترین».

### ۴.۴ حساب‌ها (MT5)
- شناسایی خودکار از رویدادها؛ ویرایش نام/یادداشت/نرخ تومان/آرشیو.

### ۴.۵ هدف‌گذاری
- هدف پولی یا کالا؛ پس‌انداز فعلی؛ درآمد ماهانه؛ تاریخ هدف.
- برنامه زنده: KPIهای پیشنهادی، نقشه راه، قابل‌یافتنی بودن، وضعیت‌سنجی.
- فعال‌سازی: پس‌انداز فعلی از حساب مرتبط خوانده می‌شود.

### ۴.۶ حسابداری شخصی
- **تراکنش‌ها:** نوع (واریز/برداشت/هزینه)، مبلغ، ارز (USD/IRT)، دسته، یادداشت، حساب (MT5 یا بانکی)، فیلتر ماه/نوع.
- **هزینه‌های ثابت:** مبلغ + اختیاری «تکرار ماهانه و روز ماه»؛ موتور `sync` هر ماه خودکار تراکنش «هزینه ثابت» تولید می‌کند.
- **حساب‌های بانکی:** نام، نوع (بانک/نقد/کیف پول)، ارز، موجودی، یادداشت.
- **تعهدات (وام/قرض/طلب):** ارز، دوره (روزانه/ماهانه/سالانه)، تاریخ سررسید، مدل اقساط (تعداد کل، پرداخت‌شده، مبلغ هر قسط).
  - **پرداخت قسط:** انتخاب حساب بانکی → اعتبارسنجی موجودی (سختگیرانه) → تبدیل ارز با نرخ → کسر موجودی + ثبت تراکنش `out` → پیشرفت تسویه → بستن خودکار.
- **خلاقاصه ماهانه:** درآمد/هزینه/خالص، نمودار جریان نقدی، **سلامت مالی** (دونات درآمد در برابر هزینه + سقف بودجه دسته‌ای با هشدار ≥۸۰٪).

### ۴.۷ گیمیفیکیشن و مأموریت‌ها
- **سیستمی (۱۰ مورد خودکار از تریدهای بسته‌شده):** trades، wins، profit، avg_r، london، positive، winrate، best، **sl_respected (انضباط آهنین)**، **rr (نسبت ریسک/ریوارد)**.
- **سفارشی:** از هدف (واریز امروز)، از هزینه (سقف خرج)، یا دستی؛ با ستاره و توضیح خودکار.
- **ستاره و سطح:** ستاره به‌ازای هر مأموریت؛ اهداف هفتگی (۱۵۰) و ماهانه (۶۰۰)؛ سطح از کل ستاره‌ها با آستانه ۱۰۰/۳۰۰/۶۰۰/۱۰۰۰.
- **نشان‌ها (Badges):** ثبت دائمی با تاریخ نخستین کسب.
- **وضعیت سه‌حالته:** todo / active / done؛ بازخورد بصری در تکمیل؛ جشن نشان جدید.

### ۴.۸ تنظیمات
- تم، پالت رنگ، زبان، ارز پایه، نمایش تومان، بازه پیش‌فرض، رمز پنل.

### ۴.۹ وضعیت سیستم
- سلامت اتصال به فایل رویداد، دیتابیس، شمارش رکوردها، آخرین خطا.

## ۶. الزامات غیرعملکردی

- **عملکرد:** پاسخ API < ۲۰۰ms؛ رفرش خودکار (۸ ثانیه) برای KPI.
- **آفلاین/محلی:** تمام داده در SQLite محلی.
- **امنیت:** فقط 127.0.0.1؛ رمز پنل اختیاری (sha256).
- **قابل‌دسترس:** RTL/LTR، i18n، تم تیره/روشن.
- **دقت ارز:** تبدیل IRT→USD با نرخ حساب (یا اولین حساب فعال)؛ در نبود نرخ، از مجموع دلاری کنار گذاشته می‌شود.
